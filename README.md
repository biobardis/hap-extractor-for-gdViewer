# hap-extractor-for-gdViewer

`haplotype_extractor_for_gdViewer` is a tool for extracting haplotype information from VCF and GFF3 files and preparing haplotype data for visualization in [gdViewer](https://github.com/biobardis/jbrowse-plugin-gdViewer).

> **Development Status**
>
> `hap-extractor-for-gdViewer` is currently under active development.
>
> The latest development code is available in the [`dev`](../../tree/dev) branch. The `main` branch is not yet intended for general use.

Features, documentation, and installation instructions will be added as development progresses.
